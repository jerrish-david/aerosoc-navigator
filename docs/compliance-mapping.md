# Compliance Mapping

## NIST CSF

- Govern: documented roles, approval policies, control rationale
- Identify: asset inventory, document classification, dependency awareness
- Protect: RBAC, encryption, secret management, secure defaults
- Detect: alert ingestion, IOC correlation, low-confidence monitoring
- Respond: triage workflow, analyst recommendations, approval gates
- Recover: audit-backed case history and lessons learned

## NIST AI RMF

- Govern: acceptable AI use and approved source boundaries
- Map: intended use and failure modes for analyst augmentation
- Measure: citation coverage, confidence, false positive rate
- Manage: human review and fallback on low confidence
