# Frontend Scaffold

Suggested stack:

- React
- TypeScript
- Vite
- TanStack Query
- Tailwind or a lightweight design system

Suggested screens:

- analyst dashboard
- case detail page
- evidence viewer
- approvals queue
- vulnerability prioritization view

Suggested components:

- case summary card
- source citation panel
- confidence badge
- approval action modal
- audit timeline

The backend is the primary focus of this scaffold. The frontend should consume the documented API and remain free of security-critical decision logic.
